PRACTICAL 1 
Installing RHEL and Studying the Linux Graphical Environment 
Aim 
To install Red Hat Enterprise Linux in VirtualBox/VMware and study the graphical 
environment, login manager, desktop environment, directory structure and file systems. 
Requirements 
• VirtualBox or VMware  
• RHEL ISO  
• 4 GB RAM or more  
• 30 GB virtual disk  
 
A. Creating the Virtual Machine 
Procedure 
1. Open VirtualBox/VMware.  
2. Create a new virtual machine.  
3. Select Linux / Red Hat Enterprise Linux 64-bit.  
4. Allocate RAM.  
5. Create a virtual hard disk.  
6. Attach the RHEL ISO.  
7. Start the VM.  
8. Select Install Red Hat Enterprise Linux.  
9. Select language and keyboard.  
10. Configure:  
• Installation destination  
• Network  
• Time zone  
• User account  
• Root password  
11. Begin installation.  
12. Reboot after installation.  
13. Log in.

B. Linux Graphical Environment 
1. Display/Login Manager 
Check the display manager: 
systemctl status display-manager 
Expected Output 
● gdm.service - GNOME Display Manager 
     Loaded: loaded 
     Active: active (running) 
Run: 
systemctl status display-manager 
Print this terminal output. 
 
 
2. Desktop Environment 
RHEL Workstation commonly uses GNOME.

Directory Purpose 
/ Root directory
