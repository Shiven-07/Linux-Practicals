## How to use

1. Select a practical by its **index number** above.
2. Open its guide for commands and **source.pdf** for the original procedure, screenshots and output.
3. Use the sample data, shell scripts and Apache examples linked in the relevant guide.
4. Perform administration exercises in a Linux/RHEL lab VM. The commands were organized from the supplied material and have not been run or verified on a Linux machine here.

The storage source explicitly requires a separate disposable virtual disk. Replace example disk names, UUIDs, account names and addresses with values for your lab.

Some source pages appear in multiple folders because the index groups topics differently or two storage topics share one page. Both original files are preserved unchanged.
